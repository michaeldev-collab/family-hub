# Home — 1024×600 (Waveshare)

**Job:** At a glance — dinner tonight, open chores / grocery counts, pinned notes, connection badge.  
**Contract:** `home` VM (+ badge may be overridden by panel RSSI/HTTP).  
**Mutations:** none.

| Region | Content |
|--------|---------|
| Header chrome (y &lt; 70) | Brand / sync / status — ShellGestures sleep + diagnostics |
| Main left | Tonight's dinner + cook |
| Right stack | Counts, last sync, next-up (first chore / grocery / note) |
| Bottom nav | Home · Grocery · Chores · Dinner · Notes · Setup |

## Acceptance

- ~1 m glance answers dinner + open work within a few seconds
- Offline / invalid schema → not a fake healthy Home (Diagnostics)
